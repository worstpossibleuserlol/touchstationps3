# Corresponding source distribution

Each published TouchStation APK release must be accompanied by a matching source archive named TouchStation-vX.Y.Z-corresponding-source.tar.gz, generated by the same GitHub Actions run.

## What the archive contains

The archive includes:

- the complete ARMSX3 repository at the exact pinned source commit used by the build;
- initialized source for upstream Git submodules at their pinned gitlink revisions;
- the Android application source after all TouchStation patches and dated file notices have been applied;
- the unchanged ARM64 native libraries staged from the documented ARMSX3 release APK;
- the TouchStation patch scripts, build workflow, GPL-2.0-only license text, third-party notices, and these instructions;
- TOUCHSTATION_MODIFICATIONS.md, listing upstream application files changed or added by TouchStation, including binary resources that cannot carry an inline source comment.

The archive excludes Git metadata and generated Gradle/build output. It does not include PS3 firmware, commercial games, user data, or private signing keys.

## Rebuilding

1. Extract the archive.
2. Read the upstream build documentation and submodule-specific instructions included in the ARMSX3 tree.
3. Use the exact Android, Gradle, and JDK versions shown in the included GitHub Actions workflow.
4. The staged ARM64 libraries in android/armsx3-ui/app/src/main/jniLibs/arm64-v8a are the unchanged libraries used by the published APK. The workflow obtains them from the upstream ARMSX3 1.6.4 release APK.
5. Build the Android application from android/armsx3-ui using the command in the workflow.

The archive and APK are generated from the same workflow run. Verify the accompanying SHA-256 file before using the archive.

## Distribution rule

Do not publish an APK unless the corresponding-source archive and checksum are also generated and attached to the same GitHub release. This project aims to satisfy the corresponding-source route in GPL version 2, section 3(a); maintainers should review every release asset and all third-party component terms before distribution.

This document is project compliance documentation, not legal advice or a certification that every third-party component has been independently audited.
